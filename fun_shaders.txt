To help you understand how these filters are built technically (whether in a game engine like Unity/Unreal, a web-based WebGL tool, or a mobile app), I have annotated the list using the following technical key:

### **Implementation Key**
* **[1S]** – **Single Shader:** Can be achieved in one pass (simple pixel math or UV manipulation).
* **[MS]** – **Multiple Shaders (Fixed):** Requires a sequence of specific steps (e.g., Edge detection → Blur → Blend).
* **[VS]** – **Variable Linear Shaders:** The number of passes depends on user settings (e.g., strength of blur or "stacked" effects).
* **[CG]** – **Complex Graph:** Requires non-linear logic, branching paths, or temporal feedback loops.
* **[TX]** – **External Texture Required:** Needs a LUT (Look-Up Table), noise map, paper texture, or border mask.
